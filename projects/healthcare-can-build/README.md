# Healthcare Can Build

> How might we give healthcare professionals a clear first step into
> building tech products — so they stop spinning and start doing?

This is a design thinking project using the
[ai-augmented-design-thinking](https://github.com/YOUR-USERNAME/ai-augmented-design-thinking)
framework. Each phase folder mirrors the framework's structure and holds
the filled-in outputs from the coaching agents.
