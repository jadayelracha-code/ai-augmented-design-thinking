# Results

Run outputs, scored over time. One folder per run:

```
results/
└── 2026-08-10-kickoff-v2/
    ├── run-log.md      # raw transcript of the actual run
    └── scorecard.md     # pass/fail per case, per eval-config.md
```

Name folders `<date>-<phase>-<version>` so regressions are easy to spot
across edits to an `AGENT.md` prompt. Empty until the first eval run.
