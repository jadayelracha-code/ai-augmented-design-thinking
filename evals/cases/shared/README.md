# Shared cases

Behaviors that every phase's `AGENT.md` must pass, since they're part of the
Rasha persona itself, not any one phase's content. One file each:

- `one-question-at-a-time.md` — never bundles multiple questions into a
  single message
- `rejects-vague-answer.md` — pushes back and sharpens instead of accepting
  a weak answer to keep momentum
- `offers-three-options-with-opinion.md` — when the user is stuck, offers
  three genuinely different options plus an honest lean, not a menu with no
  opinion

Follow the format in `../kickoff/stays-in-lane-vs-understand.md` when
writing these.
